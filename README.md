git clone
open in vscode (best ide in the world)
create .env file 
create env variable: CANVAS_API_KEY=<cat_courses access token>
if you dont have one, go to https://catcourses.ucmerced.edu/profile/settings and create new access token

then run command: npm install
to install stuff ;)

then run command: node index.js

onces the script finishes and aggregatedSharedUsers.json has stuff you can open index.html in live server
to see who you share the most number of classes
